# Forge 1.20.1 MDIC command buffer parity plan

This document supersedes the old G5/G6 debug command-buffer plan.

The formal command buffer path must match original Voxy `MDICViewport`,
`cmdgen.comp`, and `MDICSectionRenderer` contracts. Debug DrawArrays/indirect
proofs are deprecated and must not evolve into production command ownership.

## Original command sources

```text
src/main/java/me/cortex/voxy/client/core/rendering/section/backend/mdic/MDICViewport.java
src/main/java/me/cortex/voxy/client/core/rendering/section/backend/mdic/MDICSectionRenderer.java
src/main/resources/assets/voxy/shaders/lod/gl46/bindings.glsl
src/main/resources/assets/voxy/shaders/lod/gl46/cmdgen.comp
src/main/resources/assets/voxy/shaders/lod/section.glsl
```

## Deprecated prior route

The following are historical proof only:

```text
ForgeMdicCommand
ForgeMdicCommandPlanner
ForgeMdicDebugRenderer
ForgeMdicDebug*CommandBuffer
DrawArraysIndirect debug commands
synthetic cmdgen validation commands
K10-owned preview DrawCommand buffers
```

They must not be used as formal command buffers.

## Required parity

Forge formal command ownership must provide:

- draw command buffer with original indexed indirect layout;
- draw count/parameter buffer matching original binding expectations;
- visibility buffer owned by `MDICViewport` equivalent;
- indirect lookup/render-list buffer owned by viewport/traversal path;
- position scratch buffer;
- command generation through production `cmdgen.comp`;
- draw submission through formal `MDICSectionRenderer` equivalent.

## Validation

Validation must compare against original shader and Java contracts:

- `DrawCommand` stride and fields match `bindings.glsl`;
- `cmdgen.comp` consumes real section metadata and visibility inputs;
- command output is not generated by a debug CPU planner;
- generated commands are submitted only by the formal MDIC renderer;
- deprecated debug/preview command buffers are absent from the formal path.
