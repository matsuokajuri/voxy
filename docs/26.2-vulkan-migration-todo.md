# Voxy 26.2 Vulkan 完整迁移 TODO

状态日期：2026-07-15
目标分支：`26.2-vulkan`
当前阶段：Round V–VII 前半源码接线已完成；Round I–IV 的 capability、多设备与完整生命周期验证仍在进行
设计依据：`docs/26.2-vulkan-migration-design.md`

本文件是 26.2 Vulkan 移植的唯一进度账本。目标不是“出现 Vulkan 画面”，
而是在保持 Minecraft 26.2、Fabric Loader 0.19.3、Fabric API 0.152.2、
Sodium 0.9.1、Iris 1.11.2 和 Java 25 不变的前提下，用 Vulkan 专属实现
接管原 Voxy OpenGL 正式渲染链，并保持其算法、数据布局、所有权、执行顺序、
生命周期和性能语义。

## 勾选规则

- `[x]` 只表示该项已接入正式链并完成该项要求的验证。正在开发、仅能编译、
  仅通过临时 probe、仅产生测试像素或只有设计时都保持 `[ ]`。
- 完成一项时，必须在同一批改动中把对应 `[ ]` 改为 `[x]`，不能延后集中补勾。
- 一项只完成一部分时先拆成可独立验证的子项，只勾已完成的子项。
- 发现新的必需工作、上游合同或 blocker 时，先把它加入正确依赖位置再继续实现。
- 不得删除、合并或改写未完成项来隐藏缺口；范围变化必须记录原因。
- GPU/shader probe、readback、RenderDoc capture、离屏测试和审计日志仅为诊断证据，
  不能单独满足正式 renderer readiness。
- 每轮完成时记录正式 owner、编译、必要的 `runClient`、Vulkan validation 和实际
  世界视觉确认等可复现证据。
- 只有所有适用项均为 `[x]` 且最终审计没有 blocker，才可宣布移植彻底完成。

## 本清单合法性审查（2026-07-15）

审查基准：根目录 `AGENTS.md`、用户确认的任务边界、原 Voxy 正式 OpenGL 链和

| 审查项 | 结论 | 说明 |
|---|---|---|
| fallback 或双 renderer | 合法 | 明确禁止 GL、preview 和弱化算法 fallback；GL 只作只读行为基线，等价 owner 完成后退役。 |

| 锁定版本 | 合法 | 开始、验证和交付阶段均要求版本不变。 |
| Vulkan API 适配边界 | 合法 | 只允许 descriptor、barrier、pipeline、layout 等 API 适配；数据与算法合同保持原链。 |
| 诊断冒充 readiness | 合法 | probe、readback、capture 和 offscreen evidence 被明确排除。 |
| 过早删除 OpenGL owner | 合法 | 先完成等价 owner、消费者迁移和验证，再退役 GL owner。 |
| Sodium/Iris/lifecycle/cross-GPU | 合法 | 均有独立阶段和验收项，未验证时保持未完成。 |
| 不可执行的性能承诺 | 合法 | 要求同场景测量并解决实质性回退，没有虚构固定数字。 |
